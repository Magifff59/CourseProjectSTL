# Enchantix Logger – Система управління даними
**Курсовий проєкт на тему:** *"проєктування системи управління даними з використанням `std::vector` для системи логування та трасування"*

---

## 💡Про проєкт
Це інтерактивна система для збору та аналізу логів. Головна мета – показати, як можна ефективно керувати масивами даних у C++, використовуючи контейнер `std::vector` та принципи об’єктно-орієнтованого програмування.

---

## 🚀Головні "родзинки" системи

* **Ефективне управління через** `std::vector` –
  вся робота з пам'яттю побудована на векторах. Використано ідіому **Erase-Remove** для швидкого видалення непотрібних лоґів та алгоритм `std::sort` з лямбда-виразами для миттєвого перемикання порядку виводу.

* **Автоматичне профілювання (RAII)** –
  клас `Profiler` автоматично заміряє час виконання функцій. Створює об'єкт та засікає час, коли функція завершується, то сам рахує мілісекунди й записує результат у лоґ.

* **Пошук, фільтрація та створення рапортів** –
  реалізовано гнучкий пошук за ключовими словами та фільтрація за рівнями важливости або часом, також результати пошуку можна експортувати в окремий `.txt` файл для створення вибіркових звітів.

* **Аналітика сесії** –
  перед закриттям програма виводить підсумок сесії: початок та кінець сесії, її тривалість, кількість оброблених лоґів та час останньої компіляції програми.

---

## 📂 Структура проєкту

* **`include/logger.h`** – структура класів, макроси трасування та описи методів.
* **`src/logger.cpp`** –  реалізація методів.
* **`src/main.cpp`** – функціонал системи та генератор тестових лоґів.
* **`logs.txt`** – основний файл, куди дані з вектора автоматично зберігаються при виході.
* **`filter_report.txt`** – другорядний файл, куди дані з сортування можуть бути збережені (якщо користувач не дав власну назву).
* **`search_report.txt`** – другорядний файл, куди дані з пошуку можуть бути збережені (якщо користувач не дав власну назву).

---

## 🔨 Як зібрати та запустити (VS Code Terminal)

* **Зібрати проєкт в один файл:**
  ```bash
  g++ src/main.cpp src/logger.cpp -I include -o logger_app
  ```
* **Потім ввести команду запуску:**
  ```bash
  ./logger_app.exe
  ```

## ‼️ Примітка 
* У проєкті є файл `run.bat` для простого відкривання та показу програми, але на банері не працюють кольори.
