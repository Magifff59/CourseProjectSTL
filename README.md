# База-ґрунт-фундамент команд для роботі у терміналі:
- *збирає ВСІ ФАЙЛИ в один exe*
` g++ src/main.cpp src/logger.cpp -o logger_app `

- *запуск проги*
` ./logger_app `

## Команди для роботи з GIT
- *додати файли до змін*
` git add . ` 
*(крапочка вкінці свідчить, що будуть додані УСІ файли в чергу на збереження)*

- *збереження чекпоінтів а.к.а комітів*
` git commit -m "опис того, що зробив" `

- *переглянути історію збережень*
` git log --oneline `

- *ВІДКАТ ДО ОСТАННЬОГО ЧЕКПОІНТУ ВРАЗІ, ЯКЩО ВСЕ ПІДЕ ПО ПИЗДІ*
` git restore . ` 
*(крапочка вкінці означає, що УСІ файли вернуцця до останнього чекпоінту)*

## Структура проєкту на покишо
- ` include/ ` — заголовкові файли (.h)
    - ` logger.h `
- ` src/ ` — вихідний код (.cpp)
    - ` logger.cpp `
    - ` main.cpp `
- ` logger_app.exe ` — готовий застосунок
- ` logs.txt ` — результат роботи лоґеру


шо нада на курсач:
Що нам треба зробити далі (згідно з темою):
Оскільки це "система управління даними", викладач захоче побачити не просто запис, а саме управління. Тобто, нам треба додати можливості:

Фільтрація: Показати тільки помилки (ERROR) або тільки повідомлення за певну дату.

Пошук: Знайти запис за ключовим словом.

Видалення/Очищення: Можливість видалити старі логи або очистити весь вектор.

Трасування (Tracing): Це трохи глибше, ніж просто лог. Це коли ми відстежуємо шлях виконання програми (наприклад, яка функція викликала іншу).
